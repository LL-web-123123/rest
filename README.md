# 抖音群聊 AI 助手

一个能接进抖音群聊的 AI 助手：让它读群消息、按上下文接话、被 @ 就回、没人理的时候自己去贴吧学说话。

跑在 Windows 上，一个本机网页当控制台，模型用 DeepSeek。

---

## 先说清楚三件事

**一、它用的不是官方接口。**

抖音官方的群开放能力个人号申请不下来。这个项目走的是**抖音桌面版客户端的 IM 长连接**，跟你在电脑上开抖音聊天走的是同一条路。

**二、号的风险是你自己的。**

违反平台规则的操作（高频刷屏、批量骚扰、多号同开）会带来限流或封号。别拿它去大群刷，别开一堆号一起上。

**三、请只用你自己的号、你自己有权限的群。**

不要拿别人的账号登录，不要把群里的内容转到别处。

---

## 需要什么

- Windows 10 / 11
- Node.js 22.5 或更高（[nodejs.org](https://nodejs.org/)）
- 一个能扫码登录的抖音号
- 一个 DeepSeek 的 API key（[platform.deepseek.com](https://platform.deepseek.com/)）

不需要显卡。

---

## 装

1. 解压到一个**没有中文、没有空格**的路径，比如 `D:\dybot`。
2. 双击 `install.bat`，等它把依赖装完。
3. 双击 `start.bat`。会开一个黑窗口，**别关它**，关了机器人就停。
4. 浏览器打开 <http://127.0.0.1:8799>

想确认环境有没有问题，双击 `check_env.bat`。

---

## 配

在控制台里按顺序做：

1. **填 key**：DeepSeek 那栏粘贴 key，点保存。
2. **扫码登录**：点登录，手机抖音扫一下。登录凭据会存在 `data/accounts/`，下次不用再扫。
3. **填人设**：人设栏里写它是谁、怎么说话。默认给了一段通用模板，改成你想要的样子。
4. **勾群**：只勾你要它接的群。**这一步不做，它一句话都不会回。**
5. **填老大 uid**（可选）：填你自己的 uid，你说的话它会优先接，别人冒充你它不认。
6. **打开监听**：把监听开关打开。

---

## 省钱

它每次说话都要把最近一段群聊整个读进模型，所以**记多少条直接决定花多少钱**。

- 记忆 200 条、四万字：一天一块钱上下
- 记忆 1000 条：同样的回复量，一天五块往上

默认就是省钱那档。觉得它记性不够再往上调。

---

## 它都会什么

- 被 @ 必回，没人 @ 就看上下文决定接不接
- 群里安静一会儿，自己去贴吧刷帖学那边的说话方式，学完写进 `data/brain/` 里的笔记
- 群里发图、发视频，它会真去看（视频用 ffmpeg 抽帧）
- 有人刷礼物会道谢
- 刷屏会踢（默认真踢，可以在设置里改成只记录）
- 说不到的梗会问，不硬编

---

## 可选功能

**贴吧学说话**：不登录也能读，只是层数少。想读更深，先装 playwright 再跑一次登录：

```bash
npm i -D playwright
npx playwright install msedge
node scripts/tieba-login.mjs
```

**看视频**：需要 ffmpeg，把路径填进设置，或者加进 PATH。

**梗库**：`data/memes.json` 是可选的本地梗库，自己放一份就行，格式见 `src/bot/memes.mjs`。不放也不影响主流程。

## 常见问题

**群里有消息它不回**
先看「群」有没有勾上，再看监听开关。两个都对就看黑窗口有没有报错。

**登录过期**
它不会响，就是不说话。回控制台重新扫码。

**8799 打不开**
多半是上次的黑窗口没关干净，端口还占着。任务管理器里结束掉那个 node 进程再启动。

**回复很慢**
关掉思考模式，或者把记忆条数调小。

**被提示 key 无效**
复制的时候多带了空格；或者这个 key 没有余额。

```
src/            代码
  bot/          大脑、提示词、上下文、梗库
  idle/         贴吧
  web/          本机控制台
public/         控制台页面
scripts/        环境检查、贴吧登录等脚本
data/           运行数据（config.json、登录凭据、日志、上下文）—— 不进版本库
```
